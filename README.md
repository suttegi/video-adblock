# Video player ad cleaner

Userscript-адблокер для онлайн-видеоплееров: вырезает рекламные VAST/VMAP/VPAID-ролики, пропускает прероллы, блокирует попапы и рекламные скрипты/iframe. Работает и внутри same-origin iframe плеера.

Что делает:

- запросы к рекламным доменам и `/vast`, `/vmap`, `/vpaid` → подменяются пустым VAST;
- рекламные `<script>`, `<iframe>`, `<img>` не вставляются в страницу;
- рекламное видео в `<video>`/`<source>` не загружается, а если проскочило — глушится, скрывается и проматывается до конца;
- автоматически жмёт кнопку «Пропустить» / «Skip»;
- блокирует `window.open` (попапы).

## Установка

Скрипт нужно класть в расширение для пользовательских скриптов — **User JavaScript and CSS** (или аналог: Tampermonkey, Violentmonkey).

### User JavaScript and CSS (Chrome)

1. Установить расширение [User JavaScript and CSS](https://chromewebstore.google.com/detail/user-javascript-and-css/nbhcbdghjpllgmfilhnhkllmkecfmpld).
2. Открыть расширение → **New rule** (Добавить правило).
3. В поле URL указать сайт с плеером, например `*://example-cinema.net/*`. Можно `*://*/*` для всех сайтов, но см. раздел «Ограничения».
4. Во вкладку **JS** вставить содержимое файла [`video-adblock.user.js`](./video-adblock.user.js).
5. Сохранить (**Save**), обновить страницу.

Для нескольких сайтов — отдельное правило на каждый или одно общее правило.

### Tampermonkey / Violentmonkey

Создать новый скрипт, вставить содержимое `video-adblock.user.js`, сохранить. По умолчанию `@match *://*/*`; чтобы ограничить конкретными сайтами, замените строку `@match` на нужные (можно несколько строк `@match`).

## Добавить рекламный домен

Открыть DevTools → Network, найти домен, с которого грузится реклама, и дописать его в массив `AD_HOSTS` в начале скрипта. Поддомены блокируются автоматически.

Не добавляйте домены, с которых грузится само видео (например `voidboost`, `voidaxel` на HDRezka) — иначе перестанут играть серии.

## Проверка

DevTools → Console: при работе скрипта появляются сообщения с префиксом `[AB]`.

## Ограничения

- Скрипт полностью блокирует `window.open`. На сайтах, где попапы нужны (вход через Google/соцсети, оплата), это сломает функциональность — поэтому лучше включать его только на сайтах с видео, а не на `*://*/*`.
- Видео с расширением картинки в URL (`.png`, `.jpg`, `.gif`, `.webp`) считается рекламой — так маскируются рекламные ролики.
- Iframe плеера с другого домена (cross-origin) скрипт изнутри не патчит; для него нужно отдельное правило на домен плеера.
